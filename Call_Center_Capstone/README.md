# Call Center Service Level Analytics Capstone

## Overview
This capstone project analyzes call center operational data to identify factors that influence service level performance.

The project includes:
- Data cleaning and preprocessing
- Exploratory data analysis
- Correlation analysis
- Python visualizations
- Power BI dashboard development

## Business Question
What operational metrics most strongly influence call center service level performance?

## Tools Used
- Python
- Pandas
- Matplotlib
- Power BI

## Dataset
Public call center dataset obtained from Kaggle.

## Key Findings
- Increased waiting time was associated with lower service levels
- Slower answer speed negatively impacted service performance
- Higher abandonment rates corresponded with reduced service levels
