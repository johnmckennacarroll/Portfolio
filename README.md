Welcome to my data analytics portfolio. This repository contains selected projects demonstrating skills in data cleaning, exploratory analysis, business intelligence, dashboard development, and data visualization using real-world and synthetic datasets.

## 📞 Project 1: Call Center Service Level Analytics Capstone
**Tools:** Python, Pandas, Matplotlib, Power BI  

Capstone project analyzing call center operational data to identify key factors influencing service level performance. This project includes data cleaning, exploratory data analysis, correlation analysis, Python visualizations, and a Power BI dashboard summarizing key operational metrics.

Key focus areas include answer rate, average answer speed, waiting time, abandoned calls, and service level performance.
